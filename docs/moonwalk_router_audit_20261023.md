## 修复与补测

1. **重新加载权重后的旧缓存。** 原实现没有使已运行 Actor 的 KV 缓存失效。
   现在加载后同时清空两分支缓存及门控诊断，避免使用旧权重产生的历史键值。
2. **Adam 优化器参数范围。** AdamW 已过滤冻结参数，Adam 分支之前包含全部参数。
   现在两种优化器都只接收允许训练的参数，并分别测试专家阶段和 gate 阶段。
3. **原 gate 特征隔离测试过弱。** 最后一层零初始化会让任何输入都产生相同概率，
   因此旧测试无法真正检验特征白名单。现在用非零 gate 检验：机器人观测改变不影响
   logits，而参考改变确实影响 logits。
4. **实际切换和缓存回绕。** 新增逐环境交替选择两分支的测试，在长度 4 的缓存上
   运行 13 步，穿插局部和全局 reset，同时验证完整与分块推理；结果与两个独立、
   始终处理实际历史的控制器一致。两分支应共享历史时间线，不应要求它们的 K/V 数值相同。

## router 对旧动作的边界

冻结参数解决的是参数遗忘。soft gate 非零时会改变动作；hard gate 误选也会改变行为。
测试明确验证了这种差异，不能把“原模型冻结”写成“自动路由绝不会影响旧动作”。
强制 base 或 hard 正确选中 base 时直接返回原输出；但从滑步切回后，物理状态已经
受到之前控制影响，缓存一致也不等于运动衔接稳定。后续必须测试普通动作负例误选率、
旧动作完成率和实际连续切换，不能仅比较网络权重或单帧输出。
