# 太空步统一策略验证结果：G2

本轮验证已完成。G2 在本报告范围内通过原生仿真验证：通用策略保持冻结，自动路由能在站立、滑步、站立之间切换，已测旧动作保持。它不是未见太空步或真机泛化的证明。

## 可复用产物

- 完整模型包：`test_outputs/sliding_router_G2_review_20261023/model_G2.pt`，同目录含 `config.yaml`、独立 actor/critic 权重及哈希清单，没有指向旧实验的符号链接。
- 代码：`holomotion/src/modules/sliding_actor.py`；原生 PPO 接入在 `holomotion/src/algo/ppo_tf.py`。
- 机器报告：`test_outputs/sliding_router_G2_final_validation.json`；包内另有 `validation_report.json`。
- 完整复合 checkpoint 严格加载，两个控制器和 gate 在评测配置中都冻结；保留原观测、动作和噪声接口。训练优化器元数据仅供留档，继续训练需新建 finetune 优化器。

## 静态与训练证据

121 项 CPU 回归通过，包括冻结、无参数别名、严格初始化/恢复、归一化/噪声、双分支历史、缓存回绕、分块、局部/全局 reset 和序列重算。时序硬 gate 仅用于评测，PPO 明确拒绝该模式。

真实 `model_11999` 的通用网络、归一化和噪声共 48 个保存张量逐位未变。实际 G 权重还完成 19 步原输出逐位一致、45 步分块/reset 预检；独立模型包再次严格加载成功。

滑步专家沿用 B 的 500 次、16 环境学习结果；本轮没有重复专家训练。原内部 MoE 均衡损失保留，权重 0.01，只作用于滑步策略内部；上层 gate 没有要求两分支均匀使用的负载均衡。

## 站立→滑步→站立：实际连续仿真

800 帧合成参考有 790 个有效帧（15.8 秒），G2 全部完成。第 143 帧（2.86 秒）进入专家，第 586 帧（11.72 秒）退出；仅两次切换。中央原始滑步参考全部选择专家，两侧站立阶段误选为零，切换都在参考插值段内。

## 为什么最终采用 G2

G 能完成切换，也保持原 11 窗口；但独立瞄准负例出现两次误选，共 51 帧。这个反例被保留，G 没有被标为验收通过。

G2 不修改任何权重，仅把进入阈值从 0.5 提高到 0.9995564388275147（原开发验证集滑步概率最小值减 1e-4），退出阈值仍为 0.2，进入/退出分别要求连续 20/10 步。校准不使用新瞄准分数；原 8 个负例随后降级为开发诊断，并另选 8 个新来源作最终对照。

上层 gate 只用 372 维任务参考，屏蔽与实际跟踪姿态耦合的 60 维参考朝向，保留原模型输入不变。均值/尺度仅在训练分区估计，并折叠进 gate 首层，旧归一化未改变。

## 验证边界与资源

- 只有一个原始滑步参考和一个由它构造的连续片段；没有未见滑步泛化证据。
- 支撑、接地和配对指标是几何/速度代理，未记录逐脚接触力；配对机制尚未达到 100%。
- 硬切换仍有动作向量跳变，完整跑完和无抖动不等于动作 C0 连续或真机安全。
- 未验证 ONNX、实时部署、MuJoCo sim2sim 或真实机器人。
- 初始参考自身的支撑脚速度与“支撑固定”目标不一致，原数据保持不变，详见前期报告。
- 本轮 15 个 G/G2 评测作业全部退出码 0，采样显存峰值 3070 MiB；前期专家训练峰值 3208 MiB。始终一个本任务 GPU 作业，10 GiB 启动门槛、4 GiB 共享余量；未停止、调整其他人的训练，无提交/推送。
